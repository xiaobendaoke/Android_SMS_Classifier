中文四分类标注说明（已按主规格重写）

打开文件：zh_pilot_800.csv
填写两列：
  - label：TRANSACTION / AD / HARASS / FRAUD / NEEDS_REVIEW
  - annotator：你的名字

════════════════════════════════════
一、四类定义（先看懂再标）
════════════════════════════════════
TRANSACTION 事务：用户预期要收到的业务结果
  （验证码、扣款到账、账单、套餐余量、快递取件、订单状态等）

AD 广告：正规商家促销推广，目的是让你买/办业务
  （到店优惠、办卡送礼、升套餐折扣——不骗你转账）

HARASS 骚扰：不靠“骗转账”，但内容扰民
  （催收、灰产贷款推销、成人、赌博招揽、发票代开等）

FRAUD 诈骗：靠欺骗造成损失
  （假中奖、钓鱼链接、冒充公检法/客服、要验证码密码、诱导转账）

不确定 → NEEDS_REVIEW（不要硬猜）

════════════════════════════════════
二、强制判断顺序（必须按这个顺序问）
════════════════════════════════════
① 是不是在骗我？（假身份/假奖励/要码要钱/钓鱼）
     → 是：FRAUD
② 是不是账户/订单/认证/物流/套餐余量等“业务结果告知”？
     → 是：TRANSACTION
③ 是不是正规商家在促销、拉新？
     → 是：AD
④ 是不是催收/灰产/成人/赌博/强行推销（但不是典型诈骗）？
     → 是：HARASS
⑤ 其他 → NEEDS_REVIEW

注意：不是「先看银行/验证码就标事务」！
      也不是「有链接就标诈骗」！

════════════════════════════════════
三、易混例子（标错最多的）
════════════════════════════════════
招商银行：消费成功 50 元           → TRANSACTION
招商银行：办卡送积分优惠           → AD
“招行客服”：点链接解冻账户         → FRAUD
移动：流量剩余提醒                 → TRANSACTION
移动：升套餐享折扣                 → AD
快递取件码                         → TRANSACTION
美发店充值优惠                     → AD
无抵押放款加微信                   → HARASS（若骗手续费→FRAUD）
恭喜领 iPhone 点短链               → FRAUD
同学约打球 / 闲聊                  → NEEDS_REVIEW
