# 文件夹说明

**路径：** `Android_SMS_Classifier\android\classifier-sdk\src\main\java\com\oppo\smsclassifier/`

---

## 文件清单

| 文件 | 用途 | 备注 |
|------|------|------|
| `AssetLoader.kt` | Asset 读取辅助：从 Android assets 加载文本资源 |  |
| `ByteEncoder.kt` | 字节编码器 Kotlin 实现：UTF-8 → 固定长度 int32 token 序列 |  |
| `ClassificationResult.kt` | 分类结果数据类：category、action、confidence、reasonCode 等 |  |
| `DecisionRouter.kt` | 决策路由器：综合规则信号 + 模型概率 → 最终分类与 action |  |
| `LiteRtClassifier.kt` | TFLite/LiteRT 模型封装：反射加载 Interpreter，支持 INT8 反量化 |  |
| `ModelMetadata.kt` | 模型元数据：加载 model_metadata.json（版本、标签、阈值、输入长度） |  |
| `RuleDefinition.kt` | 规则数据类：id、language、type、priority、pattern、categoryHint 等 |  |
| `RuleEngine.kt` | 规则引擎：加载规则 JSON → collectSignals（匹配模式 + 提取信号） |  |
| `SmsClassifier.kt` | SDK 主接口：classify + warmUp + close；DefaultSmsClassifier 实现 |  |
| `TextNormalizer.kt` | 文本归一化 Kotlin 实现：NFKC + 零宽字符 + 空白压缩 + 混淆替换 |  |
