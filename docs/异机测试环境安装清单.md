# 异机测试环境安装清单

> 本文件独立于主规格，专门说明：**框架代码已在弱虚拟机仓库搭好后，换到开发机 / 训练机 / 真机上还要装什么、怎么验。**  
> 主规格仍以根目录《完整实施与最终审核方案》为准。

## 1. 本机（弱虚拟机）已完成与未完成

### 已完成（可直接拷贝仓库）

- Android 多模块工程：`app` / `classifier-sdk` / `benchmark`
- SDK：归一化、ByteEncoder、JSON 规则引擎、决策路由、无模型降级
- App：默认短信角色组件、Room 分类元数据、Compose 页面骨架、离线评测页
- Python：数据 schema、合成样例 JSONL、基线/评测脚本、蒸馏剪枝量化脚本入口
- 工具：无 INTERNET 检查、敏感日志启发式扫描、发布审核骨架

### 未在本机执行（必须在异机完成）

| 项目 | 原因 |
|------|------|
| Android SDK 安装与 `./gradlew` 全量构建 | 本机无完整 SDK |
| 下载/微调多语 BERT 教师 | 体积大、算力要求高 |
| 蒸馏 / 结构化剪枝 / INT8 量化生成 `.tflite` | 依赖 TensorFlow |
| 4GB/6GB 真机 PSS / 时延验收 | 需要真机 |
| 事务召回 ≥98% 正式宣称 | 需冻结测试集与完整模型 |

## 3. 必装组件（官方来源优先）

### 3.1 通用

| 组件 | 版本建议 | 官方获取 |
|------|----------|----------|
| Git | 任意近版本 | 系统包管理器 |
| JDK | **17**（Temurin / OpenJDK） | https://adoptium.net/ 或发行版仓库 |
| Python | **3.8–3.11** | https://www.python.org/ 或系统仓库 |

### 3.2 Android 构建（开发机必装）

| 组件 | 说明 |
|------|------|
| Android Studio Ladybug+ 或 cmdline-tools | 官方：https://developer.android.com/studio |
| Android SDK Platform **34** | SDK Manager 安装 |
| Android SDK Build-Tools **34.x** | SDK Manager 安装 |
| Platform-Tools（adb） | SDK Manager 安装 |
| 接受 SDK licenses | `sdkmanager --licenses` |

配置：

```bash
# 示例（按本机实际路径修改）
export JAVA_HOME=/path/to/jdk-17
export ANDROID_HOME=/path/to/Android/Sdk
export PATH="$JAVA_HOME/bin:$ANDROID_HOME/platform-tools:$PATH"

# 仓库内创建（已被 .gitignore，勿提交）
cat > android/local.properties <<EOF
sdk.dir=/path/to/Android/Sdk
EOF
```

### 3.3 Python 轻量依赖（任何机器跑基线/数据脚本）

```bash
cd <仓库根目录>
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -U pip
pip install -r training/requirements.lock
```

含：`numpy`、`PyYAML`、`pytest`。

### 3.4 训练重依赖（仅训练机）

```bash
source .venv/bin/activate
pip install -r training/requirements-train.txt
```

典型包含（以文件内锁定/声明为准）：

- `tensorflow`（或公司批准的内部镜像等价包）
- `tensorflow-model-optimization`
- `transformers`
- `scikit-learn`（可选，基线增强）

教师权重默认：`bert-base-multilingual-cased`  
**注意**：若从 Hugging Face 等【第三方】下载，须记录哈希与许可证；**禁止上传私有短信**；内网优先用已审计缓存/镜像。

### 3.5 真机侧

- 开启开发者选项与 USB 调试
- 允许安装未知来源（或通过 `adb install`）
- 测试时准备：飞行模式、双卡（如有）、multipart 长短信样例

## 4. 异机验证命令（建议顺序）

### 4.1 轻量（无 Android SDK 也可）

```bash
cd <仓库根目录>
source .venv/bin/activate
export PYTHONPATH=training

python -m pytest training/tests -q
python training/scripts/audit_sources.py
python training/scripts/validate_labels.py
python training/scripts/train_baseline.py
python training/scripts/evaluate.py
python tools/check_no_network_permission.py
python tools/check_no_sensitive_logs.py
python tools/audit_release.py
```

### 4.2 Android 编译与 SDK 单测（需 SDK）

```bash
cd android
./gradlew :classifier-sdk:test
./gradlew :app:assembleDebug
# APK 一般在 app/build/outputs/apk/debug/
```

### 4.3 训练链（需 requirements-train + 算力）

```bash
make prepare-data
make train-baseline
make train-teacher      # 缺依赖会 exit 2 并提示
make distill
make prune
make quantize
make verify-model
make evaluate
make export-android-assets
```

产物期望：

- `android/classifier-sdk/src/main/assets/model/sms_bytecnn_int8.tflite`
- 更新后的 `model_metadata.json`（含阈值与 SHA）

### 4.4 真机验收（需 4GB/6GB 设备）

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
# 设为默认短信应用 → 收信 → 分类 → 疑似垃圾恢复
# 飞行模式下离线评测页跑 assets/eval
# 记录 PSS / 时延到 docs/performance-report.md
```

## 5. 常见问题

| 现象 | 处理 |
|------|------|
| `SDK location not found` | 配置 `ANDROID_HOME` 或 `android/local.properties` 的 `sdk.dir` |
| `train_teacher` / `distill` 退出码 2 | 安装 `training/requirements-train.txt` |
| 无 `.tflite` 仍可演示 | App 走规则引擎；无模型时处置多为 `REVIEW`，OTP 仍可 `INBOX` |
| 事务召回未达 98% | 补数据与规则，**禁止**在测试集调阈值或把低置信全判事务 |

## 6. 安全与合规（必须遵守）

1. 不得将短信正文、私有数据集、未脱敏日志上传公网。  
2. App / SDK **不得**申请 `INTERNET`，不得接入统计/崩溃上报/远程配置。  
3. 依赖优先官方仓库；第三方来源在文档中标注【非官方】或【第三方】并记录许可证。  
4. 不得做内网穿透、端口映射、公网暴露调试通道。  
5. 疑似垃圾只做可恢复隔离，**禁止自动永久删除**。
