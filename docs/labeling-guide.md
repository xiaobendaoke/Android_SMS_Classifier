# 标注指南（四分类金标准）

依据主规格 §1.2 / §9.4。标注看的是**单条短信正文意图**，不是“用户烦不烦收到”。

## 1. 四类定义（先背这个）

| 类别 | 枚举 | 一句话 |
|------|------|--------|
| 事务 | `TRANSACTION` | 用户**预期要收到**的业务结果/账户变动/认证/物流/订单/运营商服务告知 |
| 广告 | `AD` | **正规商家**推销商品服务、优惠活动，目的是让你买/办业务 |
| 骚扰 | `HARASS` | **不靠骗你转账**，但内容扰民：催收、灰产招揽、成人、赌博、硬推销贷款发票等 |
| 诈骗 | `FRAUD` | **靠骗**造成损失：冒充、恐吓、钓鱼链接、假中奖、诱导转账、索要验证码/密码 |

不确定 → `NEEDS_REVIEW`（不进训练，不进冻结测试）。

## 2. 强制判断顺序（必须按序，不要跳）

对每一条短信只问一次「它的主意图是什么」：

```text
① 是否在骗我？（假身份/假奖励/要码要钱/钓鱼）
      是 → FRAUD
② 是否是我账户/订单/认证/物流/套餐余量等“业务结果告知”？
      是 → TRANSACTION
③ 是否是正规商家在促销、拉新、办卡办宽？
      是 → AD
④ 是否是催收/灰产/成人/赌博/强行推销（但不是典型诈骗话术）？
      是 → HARASS
⑤ 其他 → NEEDS_REVIEW
```

> 关键纠正：不要一看到“银行/验证码/套餐”就标事务；也不要一看到链接就标诈骗。

## 3. 各类：典型例子 / 反例

### TRANSACTION（事务）

**标成事务的例子：**

- 验证码：「您的验证码是 123456，5 分钟内有效」
- 扣款/到账：「尾号 4118 信用卡消费 327.62 元」
- 套餐余量/话费账单：「截至本月 XX，流量剩余 XX」
- 快递：「您的包裹已到达驿站，请取件」
- 运营商纯服务告知（无推销套餐升级话术）：停机提醒、实名提醒、账单已出

**不要标成事务：**

- 银行发的「办信用卡送礼/分期优惠」→ 多半是 **AD**
- 「恭喜中奖，点链接领奖」即使带“银行”字样 → **FRAUD**
- 「验证码 + 要求你把验证码发给别人/点可疑链接转账」→ **FRAUD**（语义是骗；系统处置可另说）

### AD（广告）

**标成广告的例子：**

- 商场/门店到店优惠、开业、打折
- 明确商家名称的促销短信
- 办宽带/办会员「来电有礼」（不索要密码、不伪造公检法）

**不要标成广告：**

- 假冒官方「0 元领 iPhone，点链接」→ **FRAUD**
- 「无抵押放款、加微信下款」偏灰产 → **HARASS**（若还有“转手续费才能放款”等骗局 → **FRAUD**）

### HARASS（骚扰）

**标成骚扰的例子：**

- 催收欠款、恐吓式催收但无钓鱼转账链路
- 成人内容、博彩招揽
- 发票代开、骚扰式贷款推销（不伪造中奖/不仿冒公检法）

**不要标成骚扰：**

- 正规品牌促销 → **AD**
- 假中奖/钓鱼 → **FRAUD**

### FRAUD（诈骗）

**标成诈骗的例子：**

- 假中奖、假积分兑换要你点不明链接
- 冒充公检法/客服：账户风险、要求转账到“安全账户”
- 索要验证码、密码、银行卡完整信息
- 诈骗式“退款/退税，先交手续费”

**不要标成诈骗：**

- 真实商家促销链接（有店名、活动清楚）→ **AD**
- 纯催收（不骗转账）→ **HARASS**

## 4. 易混对照（作业必看）

| 短信像什么 | 正确类别 |
|------------|----------|
| 招商银行：消费成功 50 元 | TRANSACTION |
| 招商银行：办卡送积分/分期优惠 | AD |
| “招行客服”：账户异常，点链接解冻 | FRAUD |
| 移动：流量剩余提醒 | TRANSACTION |
| 移动：升 5G 套餐享折扣 | AD |
| 快递取件码 | TRANSACTION |
| 到店美发充值优惠 | AD |
| 无抵押当天放款加微信 | HARASS（若骗手续费则 FRAUD） |
| 中奖 iPhone 点短链 | FRAUD |
| 同学约打球 | NEEDS_REVIEW（或非目标域，勿硬塞四类） |

## 5. 英文 UCI 补充（与中文同一套顺序）

UCI 原文是 **ham / spam 二分类**，不等于四类。英文集有三个坑：

1. **大量 ham 是私人闲聊** → 标 `NEEDS_REVIEW`，不要硬塞 `TRANSACTION`
2. **大量 spam 是英国增值短信**（铃声订阅、体育短信、假中奖）→ 要拆成 AD / HARASS / FRAUD，不要一律 `FRAUD`
3. **“Account Statement / Bonus Points / Claim”** 是典型假账单领奖 → `FRAUD`，不是事务

| 英文短信像什么 | 正确类别 |
|----------------|----------|
| `WINNER!! £900 prize. To claim call 09...` | FRAUD |
| `Private! Account Statement... Claim Bonus Points` | FRAUD |
| `Your account refilled. Transaction ID KR...` | TRANSACTION |
| `Your parcel is out for delivery` | TRANSACTION |
| `Thanks for Ringtone UK subscription £5/month` | AD |
| `Update to latest colour mobiles Free! Call 0800` | AD |
| `Want 2 get laid tonight? Txt ... 150p` | HARASS |
| `FreeMsg... sexy... reply Stop to end` | HARASS |
| `Hey running late, see you at 4` | NEEDS_REVIEW |
| 朋友要你银行卡号（聊天，非冒充客服） | NEEDS_REVIEW |

## 6. 操作要求

1. 只根据**正文**判断，不要脑补“发了多少次”。
2. 一条短信只选**一个主意图**。
3. `suggested_label` 可参考，**以你填的 `label` 为准**。
4. 吃不准就 `NEEDS_REVIEW`，不要猜。
