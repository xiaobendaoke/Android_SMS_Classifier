# 文件夹说明

**路径：** `Android_SMS_Classifier\training\src/`

---

## 文件清单

| 文件 | 用途 | 备注 |
|------|------|------|
| `__init__.py` | Python 脚本/模块 |  |
| `augment.py` | 训练数据增强：零宽字符插入、空格抖动（仅训练集） |  |
| `byte_encoder.py` | UTF-8 字节级编码器：截断/填充/映射字节→token ID（用于 Byte TextCNN） |  |
| `deduplicate.py` | 精确/归一化去重工具：去除重复文本 |  |
| `leakage.py` | Train/Val/Test 分组泄露检测：ID 重叠、组重叠、父样本泄露 |  |
| `metrics.py` | 分类指标：混淆矩阵、每类 PRF、macro-F1、准确率、Wilson 区间 |  |
| `model_student.py` | Byte TextCNN 学生模型配置与 Keras 构建器 |  |
| `normalize.py` | Unicode 文本归一化：NFKC + 零宽字符移除 + 空白压缩 + 混淆字符替换 |  |
| `schema.py` | JSONL 样本 schema 与校验：SmsRecord 数据类、LABEL_ORDER、load/write_jsonl |  |
| `split_groups.py` | 分组感知的数据集划分：确保 (template_group, sender_group) 不跨 split |  |
| `train_utils.py` | 训练辅助工具（损失、回调、日志等） |  |
