# 文件夹说明

**路径：** `Android_SMS_Classifier\tools/`

---

## 文件清单

| 文件 | 用途 | 备注 |
|------|------|------|
| `_audit_out/` | 子目录 | 详见该目录下的 `简介.md` |
| `audit_release.py` | 发布审计：权限、产物哈希、SBOM、打包发布包 |  |
| `check_model_ops.py` | 检查模型操作合规性 |  |
| `check_no_network_permission.py` | 扫描 AndroidManifest.xml 是否声明 INTERNET 权限 |  |
| `check_no_sensitive_logs.py` | 检查代码中是否输出敏感信息（密钥、token 等） |  |
| `generate_sbom.py` | 生成软件物料清单（SBOM） |  |
| `generate_sbom.sh` | SBOM 生成 Shell 脚本 |  |
